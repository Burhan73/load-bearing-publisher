Privacy Policy

Load Bearing Publisher · last updated 8 October 2026

Load Bearing Publisher (“the application”) is a personal script operated by a single individual to publish videos to YouTube channels that he owns. This policy explains what the application accesses and what happens to that data.

Who uses this application

Only its operator. The application is not offered to the public, has no sign-up, and no other person can authorise it against their own account.

What the application accesses

With the operator’s explicit Google consent, the application requests these YouTube permissions and uses them only as described:

  • Upload videos — to send the operator’s own finished video files to his own channels.
  • Manage videos — to set the title, description, tags, language translations and scheduled publish time of those same uploads, and to read back view counts and retention statistics for the operator’s own videos.

The application never requests access to any other person’s account, and it cannot do so.

What is stored, and where

  • A Google OAuth token is stored as a file on the operator’s own computer, readable only by his user account. It is never transmitted anywhere except to Google when authenticating.
  • Video files, titles and descriptions are stored on that same computer.
  • No database, no cloud storage, and no analytics or tracking service is used.

What is shared

Nothing. No data obtained through Google APIs is sold, rented, shared with third parties, used for advertising, or used to train any model. The only network destinations the application contacts are Google’s own API endpoints and the royalty-free stock media services it downloads footage from.

Google user data and limited use

The application’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The stored OAuth token remains on the operator’s computer until it is deleted or revoked. The operator can revoke the application’s access at any time at myaccount.google.com/permissions, which immediately invalidates the stored token. Deleting the token file has the same practical effect.

Children

The application is not directed at children and collects no data from anyone.

Changes

If this policy changes, the updated version will be published on this page with a new date.
